About CoopGuard™

CoopGuard™ is an intelligent poultry house monitoring system designed to automate environmental management inside poultry brooders. The system continuously monitors temperature, humidity and light intensity, while automatically controlling heating and cooling devices.

System Features

🌡 Environmental Monitoring

Real-time temperature and humidity monitoring using DHT22 sensor.

💡 Light Detection

Measures light intensity using an LDR sensor.

🔥 Automatic Control

Automatically controls heating bulbs and cooling fans.

📊 Smart Dashboard

Streamlit dashboard with live data and historical graphs.

How The System Works

1

Sensors collect environmental data.

2

Arduino processes readings and compares them with chick growth profiles.

3

Heating and cooling devices respond automatically.

4

Data is displayed through LCD and dashboard.

Hardware Components

  • Arduino Uno
  • DHT22 Temperature & Humidity Sensor
  • LDR Light Sensor
  • 16×2 I2C LCD
  • Cooling Fan
  • Heating Bulb
  • MOSFET Driver Circuit
  • LED Indicators
  • Piezo Buzzer

Software Technologies

Arduino IDE (C++) Python Streamlit PySerial
